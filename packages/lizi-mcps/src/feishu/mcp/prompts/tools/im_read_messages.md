读取飞书群组、单聊或话题串的聊天记录。Read chat messages from a Feishu chat or thread. 默认 `container_id_type=chat`:读取群聊传 `container_id`(chat_id);读取和某人的单聊可传对方 `open_id`,工具会自动反查当前用户与对方的 p2p chat_id 后读取消息。读取话题回复时传 `container_id_type=thread`,并传 `container_id`(thread_id,通常 `omt_*`);如果只有主消息 ID,传 `message_id`(通常 `om_*`),工具会先读取该消息并解析 `thread_id`。thread 模式底层按 larksuite-cli 的 `+threads-messages-list` 实践调用 `im/v1/messages` 且使用 `container_id_type=thread`,默认按创建时间升序返回。chat 模式默认 `sort_type=ByCreateTimeDesc`,适合直接读取最新消息;需要按时间线回放时传 `sort_type=ByCreateTimeAsc` 并配合 start_time/end_time。start_time/end_time 支持 Unix 秒、Unix 毫秒、RFC3339/ISO 时间;无时区的日期时间按 time_zone 参数解析,未传 time_zone 时使用运行环境本地时区。time_zone 可传 Asia/Shanghai、America/Los_Angeles 或 +08:00。page_size 上限为 50(默认 20),越界会自动钳制并在返回 hint 里说明,需要更多请用 page_token 翻页。以当前登录用户的飞书权限操作。✨ 返回的每条消息的 sender 块会 best-effort 带上 sender_name 字段(已自动批量调用通讯录解析 open_id → 姓名),直接读 sender_name 即可,无需再单独调 contact_batch_get_users。返回顶层还包含 user_map(open_id → name)便于二次查询。图片/文件消息可继续用 media_download,传对应 message_id 和 file_key。
