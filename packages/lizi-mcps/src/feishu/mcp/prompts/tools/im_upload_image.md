上传本地图片到飞书,返回 image_key,用于后续通过 im_send_message(msg_type=image) 发送。Upload a local image file to Feishu and return its image_key. 支持 JPEG / PNG / WEBP / GIF / TIFF / BMP / ICO,单张不超过 10MB。典型流程: 1) im_upload_image → 拿 image_key  2) 新发群消息: im_send_message({receive_id_type:"chat_id", receive_id:"oc_xxx", msg_type:"image", content:`{"image_key":"<key>"}`});回复到消息话题: im_send_message({message_id:"om_xxx", msg_type:"image", content:`{"image_key":"<key>"}`}).
