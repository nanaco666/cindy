上传本地文件(视频/音频/文档等)到飞书,返回 file_key,用于后续通过 im_send_message 发送。Upload a local file to Feishu and return its file_key. 支持类型: opus(音频)/mp4(视频)/pdf/doc/xls/ppt/stream(其他二进制),单文件不超过 30MB。典型流程: 1) im_upload_file → 拿 file_key  2) 新发群消息: im_send_message({receive_id_type:"chat_id", receive_id:"oc_xxx", msg_type:"file", content:`{"file_key":"<key>"}`});回复到消息话题: im_send_message({message_id:"om_xxx", msg_type:"file", content:`{"file_key":"<key>"}`})。发送音频/视频时把示例里的 msg_type 改成 "audio" / "media"。
