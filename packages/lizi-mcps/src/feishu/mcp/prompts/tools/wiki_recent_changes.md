查询某个时间段内知识库节点的活动列表(编辑/新建/挂入)。List wiki nodes that had activity in a time range. 默认仅扫描 Wiki 节点树并按节点自带的 obj_edit_time/obj_create_time/node_create_time 三个时间过滤,扫完直接按窗内最大时间倒序取 limit 条;不再对全量节点调 drive.meta.batchQuery,把"修改"和"新建"折成一个 changes 数组。每条结果带 change_kinds: ("edited" | "created" | "added") 数组,告诉调用方它为什么命中(edited=obj_edit_time 在窗内,created=obj_create_time 在窗内即底层文档创建,added=node_create_time 在窗内即老文档被挂进 wiki 树)。event_filter 默认 any 返回所有活动;edited_only 只返回 change_kinds 严格只有 edited 的(排除窗内新建/挂入,即"只要修改的");new_only 只返回有 created 或 added 的。include_modifier 默认 false,要 latest_modify_user/最新修改时间这种更精确字段时再开,只对最终命中的少量节点调 drive。include_content_preview 默认 false,需要总结正文时再开;content_preview 是当前正文预览,不是更新 diff。start_time/end_time 支持 Unix 秒、Unix 毫秒、RFC3339/ISO 时间;无时区的日期时间按 time_zone 解析,未传则用运行环境本地时区。注意:飞书 Wiki 节点接口没有全空间服务端时间过滤,仍需先扫描节点树。
