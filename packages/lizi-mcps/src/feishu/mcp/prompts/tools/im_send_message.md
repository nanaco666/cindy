以"当前登录用户"的身份发送飞书消息——接收方看到的发件人就是你本人,等同于你在飞书 App 里手动发出。Send a Feishu message AS the currently logged-in user (recipient sees you, not a bot). 新发消息传 receive_id;回复已有消息传 message_id(om_xxx)。回复模式默认 `reply_in_thread=true`: 回复群消息时会进入该消息的话题流;如果飞书侧尚未为该消息生成话题,会基于该消息创建/使用话题后再回复。常用流程: 先用 contact_search 查到对方 open_id,或用 im_list_chats 找群并用 im_read_messages 找到要回复的 message_id;如果已知对方邮箱,或按姓名搜不到人,可以向用户索要邮箱并用 receive_id_type=email 直接发送。msg_type=text 时直接传纯文本到 content 即可(自动 JSON 包装);其他 msg_type 需自行拼好飞书规范的 JSON 字符串再传 content。参数示例: 新发群消息 `{"receive_id_type":"chat_id","receive_id":"oc_xxx","content":"收到"}`;回复到消息话题 `{"message_id":"om_xxx","content":"收到"}`;回复到主聊天流 `{"message_id":"om_xxx","content":"收到","reply_in_thread":false}`。
