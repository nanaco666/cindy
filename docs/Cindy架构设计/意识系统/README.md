# 意识系统

意识(Ghost,文件后缀 `.cindy`)是 Cindy 的能力单元:用户与官方都以意识形式为主机叠加能力与界面,不经发版、注入即用。

**命名体系(2026-07-08 Lizi 定案,攻壳语系;当日晚间起内外统一,曾用名"卡带/cartridge"全面退役)**:
- **品类词**:「**意识**」(英 **Ghost**、日 **ゴースト**、韩 **고스트**——Ghost/ゴースト 为攻壳正典原词,고스트 为韩文圈标准词,中文正统译法"灵魂",「意识」为 Cindy 自定);动作词整套为「**注入**(安装,攻壳"电脑化=向脑注入微型机"同语域)/ **抽离**(卸载,Cindy 原创)/ **唤醒·沉睡**(启用/停用)」。世界观与攻壳正典的分歧点(正典中 Ghost 不可复制,Cindy 宇宙中意识可封装流通)是有意为之的原创设定。名字就是名字,展示时不追加品类后缀。
- **形态(2026-07-12 Lizi 定案收敛,推翻 07-09 三形态案)**:意识只有一种产品形态——「**电子脑**(Cyberbrain/電脳/전뇌,`kind: 'chip'`)」,判据是"能和 Cindy 交互 + 有独特的渲染能力"。原三形态中的「经验」(提示词层)取消不做(Skill 已覆盖);「躯壳」(declaration 静态档)彻底移除、不留兼容层(Lizi 确认无存量包,对齐"无曾用名兼容"先例;它是 C1/C2 期的工程脚手架,使命已完成)。**形态词不上界面**:用户层只如实列"包含什么"(面板/可执行代码/模型调用等);中文「电子脑」永远写全,「记忆」保留给 agent 记忆系统。沿革与处置细节见 runtime-sandbox.md §0.5。
- **代码层**:模块目录叫 **cindy-brain**(壳中之脑,意识的容身处:`main/cindy-brain`、`renderer/cindy-brain`;2026-07-10 Lizi 定案由 brain 更名,加 `cindy-` 家族前缀与 `cindy-media` 等 Cindy 系模块对齐——"Cindy"是整个意识系统的总名,brain 只是其中意识宿主一块,不用整体名命名零件)。**数据目录仍是 `userData/brain`**(用户盘上的真实路径,已有装机数据,改名需迁移不值得;代码目录与数据目录允许分叉)。实体与 API 叫 **Ghost/ghosts**(`GhostManager`、`ghosts:*` IPC、panelKind 前缀 `ghost:`),清单文件 `ghost.json`,文件后缀 `.cindy` 不变。
- **无曾用名兼容**:更名发生在任何版本发布之前,不存在旧数据,代码中不保留 `cartridge:` 前缀 / `userData/cartridges` 目录 / `cart.json` 清单 / `?tab=cartridges` 地址的任何兼容层(2026-07-08 Lizi 定案:曾短暂写过的兼容代码同日移除)。

## 已达成的核心共识(待逐篇成文)

- **主机出厂只有两块内置面板**:会话列表 + 聊天主区(不可关闭);其余一切 UI 都是意识面板叠加,包括现在的右侧边栏(未来的「工具箱意识」)。
- **五个卡槽**:① 订阅消息事件流 ② 注册工具(底层 MCP)③ 渲染消息卡片 ④ 面板 ⑤ 模型调用申请(只能走统一模型通道)。
- **两条安全铁律**:模型调用只走主机统一通道(计费/限流/审计);意识自有授权凭证锁在沙箱私有保险库,宿主无读取接口。
- **单一形态(2026-07-12 收敛)**:意识 = 芯片卡(JS/TS 代码,跑沙箱进程)。纯 prompt 资产归 Skill 体系;早期声明卡(清单+模板)已彻底移除。
- **分发无商店**:`.cindy` 文件本地导入/直接分享;装意识前弹权限确认。
- **主界面布局树**:全局一份的 rows→panes 树,意识面板可停任意 pane / 浮层 / 独立窗口;每块面板能移动、能关闭、能弹窗、记住位置。重构策略:先统一面板接口、渲染出与现状零差异的默认布局,再逐步开放编辑与新停靠位。
