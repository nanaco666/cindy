# Cindy 架构设计

Cindy(定名,品牌拼写恒为 Cindy)= XDMaker 插件化方向的整体架构设计。核心主张:主机只做连接器(会话引擎 + 统一模型通道 + 意识运行时 + UI 外壳),其余能力与界面以「意识(Ghost,`.cindy` 文件)」形式注入/抽离。

> **命名体系(攻壳语系,2026-07-08 定案)**:品类词「**意识**」(英 **Ghost**);动作词「注入 / 抽离 / 唤醒·沉睡」;代码层模块目录叫 **brain**(意识的容身处),实体类型叫 **Ghost**。曾用名「卡带 / cartridge」已全面退役(更名早于任何发布,代码不保留兼容层)。完整词表与正典考据见 [意识系统/README.md](./意识系统/README.md)。

本目录按主题拆分子目录,一个子目录一个子系统,文档按讨论进度逐步补充,不一次性写大而全的总案。
