## 8. 实现约束

- 客户端、移动端、浏览器跳转 / 回调页必须共用同一套几何组件规格；移动端只处理画布放置与上方资产压缩。
- 浏览器回调页运行在系统浏览器，不能依赖 Electron renderer token 注入或私有协议。若使用表情图资源，应由 loopback server 同源提供或内联 data URI。
- loading 动画只能用 compositor-friendly `transform` / `opacity`；不要把 infinite 动画直接挂在 SVG path 上。
- 新 UI 颜色不得硬编码 hex pair；颜色和关键尺寸决策见 `token-decision-table.md`。
