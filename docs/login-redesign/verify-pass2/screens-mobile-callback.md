## 缺口清单

1. `SLOGAN` 在四个移动登录帧中均为 vector/资源图层；Figma 节点数据没有可抽取的文本字符、字体族、字重或字号。任务中所称 “Dream it Create it” 因此无法由该节点的可读数据逐字验证。
2. 桌面 Browser 与 Mobile Chrome 的部分 chrome 都是单张资源图层；节点数据可给出图层位置/尺寸及已单列形状的填充色，但不能取得扁平资源内部的地址、图标、字体、间距或可交互控件参数。
3. 回调卡、输入框、按钮的设计上下文给出边框颜色和 `border`，未给原始 Figma stroke thickness 数值；本文没有将其推断为任何像素值。
4. 指定桌面页壳仅含按钮实例，没有 `hover` 节点/variant；因此 hover 的填充、边框、文字等逐参数值在本次节点范围内缺失。移动端按平台规则不实现 hover。
